# Boat Battle — p5.js

A two-player, turn-based naval combat game developed using JavaScript and p5.js in December 2025.

Players control battleships, navigate different environments, and aim projectiles to defeat their opponents. The game incorporates projectile physics, environmental obstacles, wind mechanics, and power-ups.

## Features

- **Two-player gameplay:** Local multiplayer with alternating movement and shooting phases.
- **Multiple maps:** Lighthouse and Dam environments with distinct obstacles.
- **Boat selection:** Different boat types with unique weapons, movement speeds, and health.
- **Projectile physics:** Simulated gravity, projectile trajectories, and wind effects.
- **Collision detection:** Interactions between projectiles, boats, and environmental obstacles.
- **Power-ups:** Speed boosts, health regeneration, and multi-shot abilities.
- **Interactive interface:** Main menu, boat selection, health bars, animations, and sound effects.

## Technologies Used

- JavaScript
- p5.js
- Object-Oriented Programming
- 2D Graphics and Physics Simulation
- Collision Detection

## How to Play

1. Start the game and select a map.
2. Each player selects a boat.
3. Players alternate between movement and firing phases.
4. Aim projectiles using the mouse and account for wind and obstacles.
5. Reduce your opponent's health to zero to win.

### Controls

| Action | Player 1 | Player 2 |
|---|---|---|
| Move | A / D | Left / Right Arrows |
| Fire | W | Up Arrow |
| Select Boat | W / S | Up / Down Arrows |
| Aim | Mouse | Mouse |
| End Movement Phase | Enter | Enter |

## Running Locally

1. Download or clone this repository.
2. Ensure that all required images and audio files are included.
3. Start a local web server, such as VS Code Live Server.
4. Open `index.html` in your browser.
